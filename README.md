# 60分ビジュアルタイマー

赤い円盤が減っていくことで残り時間が見える、60分までのタイマー（PWA）。

- 円盤をなぞって離すとスタート、中央のつまみで一時停止・再開
- 「次の予定までセット」で予定時刻までの残り時間をセット（最大60分）
- アラーム、数字表示、画面を消さない、全画面、本体の色、メモ欄

## 公開
GitHub Pages（Settings → Pages → Deploy from a branch → main / root）で公開し、
Android の Chrome で開いて「アプリをインストール」する。

## 更新するとき
ファイルを変えたら `sw.js` の `VERSION` を上げる（例: v1 → v2）。
